# QuestMap AI

## Tagline
**Intelligent Question Discovery Through Syllabus Mapping**

## Problem Statement
The official GATE DA question bank is limited. Many concepts overlap with other GATE examinations (ST, MA, CS). Manually extracting relevant questions from these papers is time‑consuming, and simple keyword search misses context.

## Solution Overview (Current Vision)
QuestMap AI will analyse past‑year GATE question papers, infer the underlying concepts of each question using AI, and map those concepts to the official GATE DA syllabus. The output will be a single, organized collection of DA‑relevant questions grouped by DA subjects/topics.

## Evaluation & Metrics (Proposed)
- **Precision @ K** – proportion of automatically selected questions that truly belong to a DA topic (validated by manual spot‑checks).
- **Recall** – coverage of DA‑relevant questions across the source exams.
- **Confidence Score Distribution** – helps define a threshold for automatic inclusion.
